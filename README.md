# Aurion Futures Landingpage

Deploy-ready Next.js landing page for Aurion Futures.

## Included assets

- `public/assets/aurion-futures-logo.svg`
- `public/assets/aurion-futures-logo.png`
- `public/assets/aurion-mark.svg`
- `public/favicon.svg`
- `public/favicon.ico`
- `public/apple-touch-icon.png`

## Local start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Where to edit affiliate links

Open `app/page.tsx` and replace the `href: '#'` values inside `featuredTools` with your affiliate links.

Also update:

- TikTok link in the CTA section
- TheTradingExpert link if needed
- Footer social links
- Legal links to Impressum, Datenschutz, Disclaimer and Affiliate Disclosure

## Deployment

Push this folder to GitHub and import it into Vercel as a Next.js project.
